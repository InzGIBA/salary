# до зарплаты 💸

[![CI](https://github.com/InzGIBA/salary/actions/workflows/ci.yml/badge.svg)](https://github.com/InzGIBA/salary/actions/workflows/ci.yml)
[![Pages](https://github.com/InzGIBA/salary/actions/workflows/pages.yml/badge.svg)](https://github.com/InzGIBA/salary/actions/workflows/pages.yml)

Шуточное табло вылетов аэропорта «Бухгалтерия»: сколько дней осталось до зарплаты. Сплит-флап счётчик, LED-панели, механические клавиши и бегущая строка. Alpine.js + Tailwind, шрифты и вендоры локально — чистая статика для GitHub Pages. Есть киоск-режим для телевизора: `kiosk.html` или `?kiosk=true` — табло на весь экран и без кнопок.

## Правила расчёта

- ЗП по договору — **10-го числа каждого месяца**.
- Если 10-е выпадает на субботу, воскресенье или праздник — перенос **накануне**, на ближайший предыдущий рабочий день (как платят по ТК РК, ст. 86). В настройках можно переключить режим на «ближайший рабочий день» (в любую сторону).
- Учтены праздники Казахстана: Новый год (1–2 января), Рождество (7 января), 8 марта, Наурыз (21–23 марта), 1 мая, 7 мая, 9 мая, День Столицы (6 июля), День Конституции (30 августа), День Республики (25 октября), Курбан-айт.
- При совпадении праздника с выходным выходной переносится на следующий рабочий день (например, Наурыз-2026 даёт пять выходных подряд).
- 16 декабря и 1 декабря — рабочие дни и в расчёте не участвуют.
- Курбан-айт на будущие годы указан по астрономическому прогнозу: точную дату ежегодно объявляет ДУМК РК. Правительственные переносы рабочих дней не учитываются.

## Что тут можно потыкать

- **Живой счётчик** — дни, часы, минуты, секунды до зачисления; заголовок вкладки тоже обновляется.
- **«ЗП уже пришла?»** — кнопка проверки с честными отказами и конфетти в день ЗП.
- **Прогресс зарплатного месяца** — от «только начали 🐣» до «финишная прямая 🏁».
- **Счётчик денег** — укажи сумму ЗП в настройках: покажет, сколько уже заработано с прошлой ЗП и сколько капает в секунду.
- **Конвертеры ожидания** — карточки «чашек кофе», «обедов», «серий», «созвонов»… нажми на карточку, чтобы сменить метрику.
- **Календарь** — день ЗП, сегодняшнее кольцо, праздники и переносы; клик по дню рассказывает, что это за день.
- **Праздники РК** — ближайшие четыре и полный список на два года.
- **Мудрость** — генератор народной мудрости про деньги.
- **Ускорить время** — отдел кадров отклонит запрос. Три раза подряд — кнопка блокируется.
- **Демо дня ЗП** — 12 секунд праздника с конфетти, чтобы увидеть, как оно будет.
- **Пасхалка** — говорят, логотип ₸ реагирует на пятое нажатие.
- **Пульт табло** (всегда на виду): ночь/день, звук, тикер, зерно, свечение, режим анимации цифр (лопасти / сдвиг / затемнение), кнопка «киоск» и сброс — всё применяется мгновенно и сохраняется.
- **Звук табло**: синтезированные щелчки клавиш, флапы и «ка-чинг» в день ЗП; mute одной кнопкой на пульте.
- Имя, валюта (₸ ₽ $ €), время зачисления и режим переноса — в «Служебном входе», сохраняются в localStorage. Там же — готовая ссылка на киоск для телевизора.
- **Поделиться** — копирует текст с результатом в буфер обмена.
- **Киоск** — табло на весь экран телевизора, без единой кнопки. Подробнее ниже.

## Киоск: табло на телевизоре

Два способа включить:

```
https://<user>.github.io/<repo>/kiosk.html          # короткий адрес для ТВ
https://<user>.github.io/<repo>/?kiosk=true         # тот же режим через параметр
```

`kiosk.html` — просто короткая ссылка: она перенаправляет на `index.html?kiosk=true`, сохраняя остальные параметры. Работает и без JavaScript (meta refresh).

Параметр понимает `true`, `True`, `1`, `yes`, `on` и пустое значение (`?kiosk`); `false`, `0`, `no`, `off` выключают режим.

Что происходит в киоске:

- Обычная страница целиком убирается: шапка с кнопками, пульт, календарь, праздники, настройки, тосты, футер. Остаётся только табло.
- Компоновка на весь экран без прокрутки: шапка с местным временем, строка рейса (рейс · назначение · дата · время · статус), огромный сплит-флап счётчик, три нижние панели (топливо месяца, накапало / метрика ожидания, ближайший праздник) и бегущая строка.
- Всё масштабируется от 1280×720 до 4K и не ломается на вертикальном экране.
- Кнопок нет вообще. Полный экран — клавиша **F** или двойной клик; выход — **Esc**.
- Курсор прячется через три секунды покоя, экран не гаснет (Screen Wake Lock, если браузер умеет).
- Табло всегда немое: щелчки на всю комнату не нужны. Конфетти в день ЗП остаётся.
- Мудрость меняется сама каждые 15 секунд, метрика ожидания — каждые 9.
- Статусы: **ОЖИДАНИЕ** (янтарный), **ПОСАДКА** (зелёный, пульсирует в день ЗП до зачисления), **ПРИБЫЛ** (зелёное табло, конфетти, отсчёт до следующего рейса).

### Настройка ссылкой

У телевизора нет доступа к вашему localStorage, поэтому всё передаётся в адресе. Значения из ссылки живут только в памяти и не перезаписывают сохранённые настройки.

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `kiosk` | `true` / `false` | выключен |
| `name` | имя пассажира, до 30 символов | пусто |
| `amount` | сумма ЗП, число ≥ 0 | `0` (вместо счётчика денег — метрика ожидания) |
| `currency` | `₸` `₽` `$` `€` | `₸` |
| `time` | `ЧЧ:ММ`, время зачисления | `10:00` |
| `mode` | `before` / `nearest` | `before` |
| `theme` | `night` / `day` | `night` |
| `anim` | `flap` / `slide` / `fade` | `flap` |
| `ticker` | `true` / `false` | `true` |
| `grain` | `true` / `false` | `true` |
| `glow` | `0`–`100` | `60` |
| `scale` | `60`–`160` (проценты) | `100` |
| `now` | ISO-дата для отладки | текущее время |

```
# Табло в переговорке: дневная тема, сумма, зачисление в 09:30, крупнее на 20%
…/kiosk.html?theme=day&amount=450000&time=09:30&scale=120&name=Отдел%20разработки

# Проверка дня ЗП на телевизоре
…/?kiosk=true&now=2026-07-10T11:00:00
```

Готовую ссылку с вашими текущими настройками можно скопировать в «Служебном входе» → «Табло для телевизора», а кнопка **🖥 киоск** на пульте открывает её в новой вкладке.

Совет для ТВ: откройте ссылку в браузере телевизора или мини-ПК, нажмите **F** (или F11) и добавьте адрес в автозапуск. Телевизоры с overscan — поставьте `scale=90`.

## Локальный запуск

Сайт полностью статический, зависимости уже лежат в `assets/vendor/`:

```bash
python3 -m http.server 8123
# открыть http://localhost:8123
```

Пересборка CSS (Tailwind в shadcn-палитре) и тесты логики:

```bash
npm install
npm run build   # tailwindcss -> assets/css/tailwind.css
npm test        # node --test: праздники, переносы, даты ЗП, параметры киоска (41 тест)
```

Отладочный параметр `?now=` подменяет текущее время, например:

```
http://localhost:8123/?now=2026-05-08T09:00:00   # канун перенесённой ЗП
http://localhost:8123/?now=2026-07-10T11:00:00   # день ЗП, конфетти
```

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub и запушь этот проект:

   ```bash
   git remote add origin git@github.com:<user>/<repo>.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   Workflow `.github/workflows/pages.yml` сам задеплоит статику при каждом пуше в `main`.

   Альтернатива без Actions: **Source: Deploy from a branch → main / (root)** — сайт заработает сразу, `.nojekyll` уже лежит в корне.

3. Страница будет доступна по адресу `https://<user>.github.io/<repo>/`.

## Структура

```
index.html               разметка (Alpine.js): обычная страница и киоск
kiosk.html               короткий адрес для телевизора -> index.html?kiosk=true
assets/js/holidays.js    праздники РК, переносы, расчёт даты ЗП (чистый ESM)
assets/js/params.js      разбор query-параметров и сборка ссылки для ТВ (чистый ESM)
assets/js/app.js         компонент счётчика и весь интерактив
assets/css/tailwind.css  собранный Tailwind (shadcn-токены)
assets/css/styles.css    сплит-флап, LED, зерно, тикер, пульт, раскладка киоска
assets/fonts/            Oswald + IBM Plex Mono (woff2, кириллица и латиница)
assets/vendor/           alpine.js и canvas-confetti (локально, без CDN)
tests/logic.test.mjs     тесты логики дат (node --test)
tests/params.test.mjs    тесты параметров киоска (node --test)
tailwind/                исходники стилей и конфиг
```

Не является финансовой рекомендацией 😉
