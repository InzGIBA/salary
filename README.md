# до зарплаты 💸

Шуточная страница-счётчик: сколько дней осталось до зарплаты. Минимализм в духе shadcn/ui, Alpine.js, без сборки на стороне сервера — чистая статика, готовая к GitHub Pages.

## Правила расчёта

- ЗП по договору — **10-го числа каждого месяца**.
- Если 10-е выпадает на субботу, воскресенье или праздник — перенос **накануне**, на ближайший предыдущий рабочий день (как платят по ТК РК, ст. 86). В настройках можно переключить режим на «ближайший рабочий день» (в любую сторону).
- Учтены праздники Казахстана: Новый год (1–2 января), Рождество (7 января), 8 марта, Наурыз (21–23 марта), 1 мая, 7 мая, 9 мая, День Столицы (6 июля), День Конституции (30 августа), День Республики (25 октября), Курбан-айт.
- При совпадении праздника с выходным выходной переносится на следующий рабочий день (например, Наурыз-2026 даёт пять выходных подряд).
- 16 декабря и 1 декабря — рабочие дни и в расчёте не участвуют.
- Курбан-айт на будущие годы указан по астрономическому прогнозу: точную дату ежегодно объявляет ДУМК РК. Правительственные переносы рабочих дней не учитываются.

## Что тут можно потыкать

- **Живой счётчик** — дни, часы, минуты, секунды до зачисления; заголовок вкладки тоже обновляется.
- **«ЗП уже пришла?»** — кнопка проверки с честными отказами и конфетти в день ЗП.
- **Прогресс зарплатного месяца** — от «только начали 🐣» до «финишная прямая 🏁».
- **Счётчик денег** — укажи сумму ЗП в настройках: покажет, сколько уже заработано с прошлой ЗП и сколько капает в секунду.
- **Конвертеры ожидания** — карточки «чашек кофе», «обедов», «серий», «созвонов»… нажми на карточку, чтобы сменить метрику.
- **Календарь** — день ЗП, сегодняшнее кольцо, праздники и переносы; клик по дню рассказывает, что это за день.
- **Праздники РК** — ближайшие четыре и полный список на два года.
- **Мудрость** — генератор народной мудрости про деньги.
- **Ускорить время** — отдел кадров отклонит запрос. Три раза подряд — кнопка блокируется.
- **Демо дня ЗП** — 12 секунд праздника с конфетти, чтобы увидеть, как оно будет.
- **Пасхалка** — говорят, логотип ₸ реагирует на пятое нажатие.
- **Тёмная тема**, имя в приветствии, валюта (₸ ₽ $ €), время зачисления, режим переноса — всё сохраняется в localStorage.
- **Поделиться** — копирует текст с результатом в буфер обмена.

## Локальный запуск

Сайт полностью статический, зависимости уже лежат в `assets/vendor/`:

```bash
python3 -m http.server 8123
# открыть http://localhost:8123
```

Пересборка CSS (Tailwind в shadcn-палитре) и тесты логики:

```bash
npm install
npm run build   # tailwindcss -> assets/css/tailwind.css
npm test        # node --test: праздники, переносы, даты ЗП (27 тестов)
```

Отладочный параметр `?now=` подменяет текущее время, например:

```
http://localhost:8123/?now=2026-05-08T09:00:00   # канун перенесённой ЗП
http://localhost:8123/?now=2026-07-10T11:00:00   # день ЗП, конфетти
```

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub и запушь этот проект:

   ```bash
   git remote add origin git@github.com:<user>/<repo>.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   Workflow `.github/workflows/pages.yml` сам задеплоит статику при каждом пуше в `main`.

   Альтернатива без Actions: **Source: Deploy from a branch → main / (root)** — сайт заработает сразу, `.nojekyll` уже лежит в корне.

3. Страница будет доступна по адресу `https://<user>.github.io/<repo>/`.

```
assets/css/styles.css    анимации, фон, скроллбары

tests/logic.test.mjs     тесты логики (node --test)
tailwind/                исходники стилей и конфиг
```
